# Exposr

A Flutter app that checks whether an email address appears in data breaches known to
[XposedOrNot](https://xposedornot.com), and shows what was exposed and what to do about it.

## Run

```bash
flutter pub get
```

```bash
flutter run
```

```bash
flutter test
```

To look at every state (breaches found, none found, each kind of failure, long lists) without
sending anything or using XposedOrNot's free limit, run the design preview. It uses made-up
data and says so in a strip across the top of every screen:

```bash
flutter run -t lib/dev/preview_main.dart
```

## How it is put together

| Folder | What lives there |
| --- | --- |
| `lib/core` | Design tokens (`app_colors.dart`, `app_tokens.dart`) and the theme built from them |
| `lib/services` | Everything that touches the outside world: the XposedOrNot client, storage, haptics, sound, app lock |
| `lib/state` | Controllers (`ChangeNotifier`s) that hold state and call the services |
| `lib/screens`, `lib/widgets` | The four tabs and the pieces they are built from |
| `lib/models`, `lib/utils` | Plain data classes and small pure functions |
| `lib/dev` | The design preview. Not reachable from `lib/main.dart`, so not part of the app |

Screens depend on interfaces, never on a concrete service, so tests run the whole app with
fakes and no network.

The layout follows the window: a bottom bar under 600 px wide, a navigation rail up to 1024 px,
and a sidebar beyond that.

## What the app does with an address

- A check sends the address over HTTPS to `api.xposedornot.com` and nowhere else. The address
  is part of the request URL, which is how XposedOrNot's API works.
- Nothing is logged. Errors from the network layer are replaced before they leave the service,
  because their messages can contain that URL.
- An address is stored only if it is added to the Watchlist. The Watchlist and settings are
  kept with `shared_preferences`: unencrypted, in the app's own storage. Android backups are
  switched off in the manifest; an iOS device backup can include them.
- The Watchlist is checked only when asked. There is no background monitoring.

XposedOrNot's free tier allows 2 requests a second and 25 an hour per endpoint, per network
address. The app never retries a request automatically.

## Result feedback

When a check the user started finishes, the app can give a haptic and play a short sound.
A failed check gives neither.

| | No known breaches | Breaches found | Default |
| --- | --- | --- | --- |
| Haptic, iOS | notification "success" | notification "warning" | on |
| Haptic, Android | `CONFIRM` (Android 11 and later) | `CONTEXT_CLICK` | on |
| Sound | `assets/sounds/result_clear.mp3` ("high honor") | `assets/sounds/result_breach.mp3` ("low honor") | on |

Platform limits worth knowing:

- Haptics use the platform's standard haptics through Flutter's `HapticFeedback`, so the
  system's own haptic settings decide whether they are felt. There are none on desktop or the
  web, and the Settings switch says so there.
- Android has no named "warning" haptic, so a single firm click is used. On Android 10 and
  earlier there is no `CONFIRM`, so a clear result has no haptic.
- Sounds are played as quiet interface sounds: the "ambient" audio session on iOS (silenced by
  the Ring/Silent switch) and a notification-type stream on Android (silenced by silent mode,
  vibrate mode and Do Not Disturb). Neither interrupts music. Desktop and the web have no
  silent mode: the sound follows the system or tab volume.
- The two sounds are the honor-change effects from Red Dead Redemption 2 (© Rockstar Games):
  "high honor" for no known breaches, "low honor" for breaches found. They were added for
  personal character in a university project. They are not original to this project and are not
  licensed for redistribution, so replace them before releasing the app anywhere. Playback uses
  the `audioplayers` package; on Linux that needs GStreamer installed to build.

## Assets

- `assets/fonts`: Inter, under the SIL Open Font License (`assets/fonts/OFL.txt`).
- `assets/sounds`: the two result sounds, from Red Dead Redemption 2 (see "Result feedback"
  above). Not original to this project and not licensed for redistribution.
- `assets/lottie`: generated by `tool/generate_lottie.py`, so they are original to Exposr. `scan`
  is the idle and checking mark, `alert` and `success` are the results, and `shield` is the
  empty-state and lock-screen mark.
- Navigation icons: [Lucide](https://lucide.dev) through the `lucide_icons_flutter` package (the
  icon set is ISC-licensed and the package MIT). Only the four icons in use are bundled; the
  build removes the rest of the font.
- `web/favicon.png` and `web/icons/`: the logo on the app's dark tile (`#131418`, the same as the
  Android and iOS launcher icons), generated by `dart run tool/generate_web_icons.dart`. Browsers
  cache favicons hard, so after changing it a new tab or a hard refresh may be needed to see it.
